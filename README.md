# Մանկիկի զարգացման օրացույց

Տեղային վեբ հավելված՝ ծնողների հաշիվների, փոքրիկի տվյալների, հիշեցումների, աճի չափումների և նշումների համար։ Պահանջվում է JDK 11 կամ ավելի նոր տարբերակ։

## Գործարկում

IntelliJ IDEA-ում գործարկեք `src/Main.java` ֆայլի `main` մեթոդը։ Բացեք `http://localhost:8080`։ Կայքը հասանելի է միայն նույն համակարգչից։

Հրամանի տողից՝

```powershell
javac -encoding UTF-8 -d out src\*.java
java -cp out Main
```

Հիշեցումների նամակները ուղարկելու համար SMTP-ի կարգավորումները տվեք միջավայրի փոփոխականներով՝ մինչև ծրագիրը գործարկելը։

```powershell
$env:BDC_SMTP_HOST = "smtp.example.com"
$env:BDC_SMTP_PORT = "465"
$env:BDC_SMTP_USER = "sender@example.com"
$env:BDC_SMTP_PASSWORD = "your-smtp-password"
$env:BDC_SMTP_FROM = "sender@example.com"
java -cp out Main
```

Պորտ `465`-ն օգտագործում է SSL, իսկ `587`-ը՝ STARTTLS։ `BDC_SMTP_USER`-ը լռելյայն վերցվում է `BDC_SMTP_FROM`-ից։ Օգտագործեք ձեր էլ․ փոստի մատակարարի SMTP սերվերի հասցեն և, եթե պահանջվում է, հավելվածի գաղտնաբառը։ Հաղորդագրությունները ուղարկվում են ծնողի գրանցված հասցեին։

Հիշեցման նամակն ուղարկվում է ամեն օր՝ հիշեցման ամսաթվից երեք օր առաջ սկսած մինչև հիշեցման օրը ներառյալ։ Նամակի թեման հիշեցման վերնագիրն է։ Բովանդակության մեջ երևում են հիշեցման տեսակը, ամսաթիվը և ժամը։ Նույն օրվա կրկնվող նամակները կանխելու համար ուղարկված օրը պահպանվում է հաշվի տվյալների հետ։

Նամակների ուղարկման ստուգումը կատարվում է ամեն րոպե, երբ հավելվածը գործարկված է։ Հետևաբար հիշեցումները չեն ուղարկվի, եթե համակարգիչը կամ Java ծրագիրը անջատված է։

## Տվյալներ

Հաշիվները պահվում են `baby-users.properties` ֆայլում, իսկ յուրաքանչյուր ծնողի տվյալները՝ `baby-data` թղթապանակի առանձին ֆայլում։ Գաղտնաբառերը պահվում են աղիով PBKDF2 հեշի տեսքով։ Միայն գրանցված էլ․ հասցեով հիշեցումներ ուղարկելու համար օգտագործվում է տվյալ ծնողի հաշվի հասցեն։

## Տարիքային առողջության պատուհան

Ծննդյան ամսաթիվը լրացնելուց հետո տարիքի ուղեցույցը բացվում է ավտոմատ՝ ամսական մեկ անգամ։ Այն ներառում է քնի ընդհանուր տևողության CDC միջակայքը, սնուցման ընդհանուր փուլերը, ՀՀ 2026–2030 պատվաստումների տարիքային փուլերը և ԱՀԿ քաշի միջին հղման արժեքը՝ եթե պրոֆիլում ընտրված է սեռը։ ԱՀԿ թվերը բնակչության միջին հղման արժեքներ են, ոչ թե անհատական նպատակային քաշ. գնահատումը կատարվում է նաև հասակի, վաղաժամ ծնված լինելու և աճի ընթացքի համատեքստում։

Պատվաստման իրական կարգավիճակը հավելվածը չի որոշում. այն պետք է համեմատել երեխայի պատվաստման վկայականի հետ և ճշտել մանկաբույժից։ Այլ երկրի օրացույցի համար պրոֆիլում ընտրեք «Այլ երկիր»։
