# Մանկիկի զարգացման օրացույց

JavaFX desktop հավելված՝ Maven կառուցմամբ։ Ծրագիրը բացվում է JavaFX պատուհանում, իսկ գործող վեբ միջերեսն աշխատում է ներկառուցված WebView-ում։ Հավելվածը պահպանում է գրանցումն ու մուտքը, երեխայի զարգացման տվյալները և հիշեցումները։

## Պահանջներ

- JDK 17 կամ ավելի նոր տարբերակ
- Maven 3.9 կամ ավելի նոր տարբերակ

## Գործարկում

Նախագծի պանակում աշխատեցրեք՝

```powershell
mvn clean javafx:run
```

IntelliJ IDEA-ում բացեք պանակը որպես Maven նախագիծ և գործարկեք Maven-ի `javafx:run` նպատակը։ Կախվածություններն ու JavaFX-ը Maven-ը կներբեռնի ինքնաշխատ։

Սովորական փաթեթը հավաքելու համար՝

```powershell
mvn clean package
```

## Տեղային ցանցից մուտք

Երբ ծրագիրն աշխատում է, նույն Wi-Fi-ին կամ տեղային ցանցին միացած մյուս համակարգչից բացեք `http://<այս համակարգչի IP>:8080` հասցեն։ Տեղային IP հասցեն տպվում է վահանակում։ Եթե Windows Firewall-ը հարցնի, թույլատրեք Java-ի մուտքային կապը մասնավոր ցանցում։

## Էլեկտրոնային փոստի հիշեցումներ (ըստ ցանկության)

SMTP-ն կարգավորելուց հետո գործարկեք ծրագիրը հետևյալ փոփոխականներով՝

```powershell
$env:BDC_SMTP_HOST = "smtp.example.com"
$env:BDC_SMTP_PORT = "465"
$env:BDC_SMTP_USER = "sender@example.com"
$env:BDC_SMTP_PASSWORD = "your-smtp-password"
$env:BDC_SMTP_FROM = "sender@example.com"
mvn javafx:run
```

`465` պորտը օգտագործում է SSL, իսկ `587`-ը՝ STARTTLS։

## Տվյալների պահպանում

Հաշիվներն ու ընտանիքների տվյալները պահվում են նախագծի տեղային ֆայլերում։ Դրանք ներառված չեն Git-ում։
