# Baby Development Calendar

Կոնսոլային Java ծրագիր՝ երեխայի տարիքը հաշվարկելու և մինչև 24 ամսական առաջիկա ամսական օրերը ցույց տալու համար։ Օրացույցի ամսական օրերը տարիքային նշումներ են և չեն գնահատում երեխայի զարգացումը։

## Գործարկում IntelliJ IDEA-ում

Բացիր նախագիծը, հետո գործարկիր `src/Main.java` ֆայլի `main` մեթոդը։ Ծրագիրը կհարցնի երեխայի անունն ու ծննդյան ամսաթիվը։ Ամսաթիվը մուտքագրիր `YYYY-MM-DD` ձևաչափով, օրինակ՝ `2026-09-07`։

Ծրագիրը ցույց կտա տարիքը տարիներով, ամիսներով ու օրերով, ինչպես նաև առաջիկա երեք ամսական օրերը։ Անվավեր կամ ապագա ծննդյան ամսաթիվը կընդունվի միայն ուղղելուց հետո։
