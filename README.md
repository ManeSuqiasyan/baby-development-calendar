# Baby Development Calendar

Կոնսոլային Java ծրագիր ծնողների համար։ Այն հաշվում է երեխայի տարիքը, ցույց է տալիս կերակրման և քնի ընդհանուր տեղեկություն, CDC-ի տարիքային զարգացման օրինակներ, ինչպես նաև պահպանում է հիշեցումները, աճի գրառումները և ծնողի նշումները։

## Գործարկում

IntelliJ IDEA-ում բացիր նախագիծը և գործարկիր `src/Main.java` ֆայլի `main` մեթոդը։ Առաջին գործարկման ժամանակ մուտքագրիր երեխայի անունն ու ծննդյան ամսաթիվը (`YYYY-MM-DD`, օրինակ՝ `2026-09-07`)։ Հետագա գործարկումների ժամանակ ծրագիրը կօգտագործի պահպանված տվյալները։

## Հնարավորություններ

- Ցույց է տալիս տարիքը տարիներով, ամիսներով և օրերով։
- Ցույց է տալիս տարիքին համապատասխան կերակրման և քնի ընդհանուր տեղեկություն։
- Ներկայացնում է CDC-ի 2, 4, 6, 9, 12, 15, 18 և 24 ամսական զարգացման դիտարկումների օրինակներ։ Դրանք ախտորոշում չեն և չեն փոխարինում մանկաբույժի խորհրդին։
- Թույլ է տալիս ավելացնել կերակրման, քնի, բժշկի կամ պատվաստման և այլ հիշեցումներ։
- Թույլ է տալիս գրանցել քաշն ու հասակը, ինչպես նաև ավելացնել ծնողի նշումներ։
- Ցույց է տալիս մոտակա հիշեցումն ու դրա ժամին մնացած ժամանակը։

Հիշեցումները ցուցադրվում են ծրագիրը գործարկելիս. փակ վիճակում ծրագիրը ծանուցում չի ուղարկում։ Հիշեցման ամսաթիվն ու ժամը մուտքագրիր `YYYY-MM-DD HH:mm` ձևաչափով։

Պատվաստումների ժամերը ծնողն է ավելացնում՝ բժշկի հետ ճշտելուց հետո։ Ծրագիրը երկրի պատվաստումների օրացույց կամ անհատական բժշկական խորհուրդ չի տրամադրում։ Քաշն ու հասակը պահվում են որպես գրառումներ և չեն համեմատվում աճի նորմաների հետ։

Երեխայի անունը, ծննդյան ամսաթիվը, նշումները, աճի տվյալներն ու հիշեցումները պահվում են ծրագրի աշխատանքային պանակի `baby-calendar-data.properties` ֆայլում։ Այդ ֆայլը ներառված չէ Git-ում։
