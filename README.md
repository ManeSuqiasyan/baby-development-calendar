# Մանկիկի զարգացման օրացույց

Նախագիծն ունի երկու գործարկման տարբերակ․ հիմնականը սովորական բրաուզերում աշխատող կայքն է, իսկ JavaFX պատուհանը՝ առանձին desktop տարբերակ։ Երկուսն էլ օգտագործում են նույն backend-ը և տվյալների ֆայլերը։

## Պահանջներ

- JDK 17 կամ ավելի նոր տարբերակ
- Maven 3.9 կամ ավելի նոր տարբերակ

## Բրաուզերով գործարկում

Նախագծի պանակում աշխատեցրեք՝

```powershell
mvn clean compile exec:java
```

Այնուհետև բրաուզերում բացեք [http://localhost:8080](http://localhost:8080)։ Նույն տեղային ցանցի մյուս սարքից բացեք `http://<այս համակարգչի IP>:8080` հասցեն։

## JavaFX պատուհան

Բրաուզերի կայքից անկախ JavaFX պատուհան գործարկելու համար՝

```powershell
mvn javafx:run
```

JavaFX տարբերակը լռելյայն աշխատում է `8081` պորտում, իսկ բրաուզերի տարբերակը՝ `8080`-ում։ JavaFX պատուհանը ցույց է տալիս նույն կայքը ներկառուցված WebView-ում։

## Փաթեթի հավաքում

```powershell
mvn clean package
```

Կախվածություններն ու JavaFX-ը Maven-ը կներբեռնի ինքնաշխատ։

## Էլեկտրոնային փոստի հիշեցումներ (ըստ ցանկության)

```powershell
$env:BDC_SMTP_HOST = "smtp.example.com"
$env:BDC_SMTP_PORT = "465"
$env:BDC_SMTP_USER = "sender@example.com"
$env:BDC_SMTP_PASSWORD = "your-smtp-password"
$env:BDC_SMTP_FROM = "sender@example.com"
mvn clean compile exec:java
```

`465` պորտը օգտագործում է SSL, իսկ `587`-ը՝ STARTTLS։

## Տվյալների պահպանում

Հաշիվներն ու ընտանիքների տվյալները պահվում են նախագծի տեղային ֆայլերում և չեն ներառվում Git-ում։
