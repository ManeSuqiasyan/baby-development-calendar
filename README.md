# 🌼 Մանկիկի զարգացման օրացույց

Ծնողների համար պարզ ու ջերմ վեբ հավելված՝ երեխայի աճը գրանցելու, առօրյան պլանավորելու և կարևոր օրերը չմոռանալու համար։ Հարմարեցված է համակարգչի և հեռախոսի էկրաններին։

## Ինչ կարող եք անել

- Ստեղծել անձնական ծնողական հաշիվ և լրացնել երեխայի պրոֆիլը։ Գրանցումը նախատեսված է 18+ օգտատերերի համար՝ ծննդյան ամսաթվի և ինքնահայտարարության հաստատմամբ։
- Պահել աճի չափումները, նշումները և հիշեցումները ծնողի առանձին տվյալների ֆայլում։
- Դիտել տարիքի ուղեցույցը՝ քնի ընդհանուր միջակայքով, սնուցման փուլերով, պատվաստումների տարիքային փուլերով և ԱՀԿ քաշի հղումային սանդղակով։
- Էլեկտրոնային փոստով ստանալ հիշեցումներ՝ միջոցառման ամսաթվից երեք օր առաջ սկսած ամեն օր, իսկ «Կերակրում» և «Քուն» հիշեցումների դեպքում՝ նշված ժամից մոտ հինգ րոպե առաջ։

> Առողջության ուղեցույցը ընդհանուր տեղեկություն է, ոչ թե բժշկական ախտորոշում կամ անհատական խորհուրդ։ Քաշի հղումային սանդղակը պետք է մեկնաբանել երեխայի աճի ընթացքի և բժշկի գնահատականի հետ։ Պատվաստումների կարգավիճակը ճշտեք երեխայի պատվաստման վկայականով և մանկաբույժի հետ։

## Արագ մեկնարկ

Պահանջվում է **JDK 17 կամ ավելի նոր տարբերակ**։

IntelliJ IDEA-ում գործարկեք `src/Main.java` ֆայլի `main` մեթոդը։ Նույն համակարգչում բացեք [http://localhost:8080](http://localhost:8080)։ Այլ համակարգչից կամ հեռախոսից՝ նույն Wi-Fi/տեղային ցանցին միացած լինելու դեպքում, բացեք ծրագրի վահանակում տպված `http://<այս համակարգչի IP>:8080` հասցեն։ Եթե Windows Firewall-ը հարցնի, թույլատրեք Java-ի մուտքային կապը մասնավոր ցանցում։

Կամ PowerShell-ից՝ նախագծի պանակում.

```powershell
javac -encoding UTF-8 -d out src\*.java
java -cp out Main
```

## Էլեկտրոնային նամակների կարգավորում

Հիշեցումներ ուղարկելու համար հավելվածը գործարկելուց առաջ սահմանեք ձեր էլ․ փոստի մատակարարի SMTP կարգավորումները։

```powershell
$env:BDC_SMTP_HOST = "smtp.example.com"
$env:BDC_SMTP_PORT = "465"
$env:BDC_SMTP_USER = "sender@example.com"
$env:BDC_SMTP_PASSWORD = "your-smtp-password"
$env:BDC_SMTP_FROM = "sender@example.com"
java -cp out Main
```

Պորտ `465`-ն օգտագործում է SSL, իսկ `587`-ը՝ STARTTLS։ Նամակի վերնագիրը հիշեցման վերնագիրն է, իսկ բովանդակությունը ներառում է դրա տեսակը, ամսաթիվն ու ժամը։ Հիշեցումների ստուգումը կատարվում է ամեն րոպե․ նամակները չեն ուղարկվի, երբ հավելվածն անջատված է։

## Տվյալների պահպանում

Ծնողների հաշիվները պահվում են `baby-users.properties`-ում, իսկ յուրաքանչյուր ծնողի տվյալները՝ `baby-data` պանակի առանձին ֆայլում։ Գաղտնաբառերը պահպանվում են աղիով PBKDF2 հեշի ձևով։ Պարբերաբար կրկնօրինակեք տվյալների պանակը և պահուստային պատճենները հասանելի մի դարձրեք հանրությանը։

## Հանրային HTTPS տեղակայում

Հավելվածն ինքնուրույն հոսթինգ չէ․ այն պետք է գործարկվի սերվերում՝ HTTPS reverse proxy-ի հետևում։ Օրինակ՝ Caddy-ի `Caddyfile`-ում ավելացրեք ձեր դոմենը.

```caddy
calendar.example.com {
    reverse_proxy 127.0.0.1:8080
}
```

Սերվերի DNS-ը և HTTPS պորտերը պետք է ուղղված լինեն հոսթինգին։ Java հավելվածը գործարկեք `BDC_HTTPS=true` միջավայրով՝ Secure session cookie-ն միացնելու համար։ Արտաքինից հասանելի պահեք HTTPS proxy-ն, ոչ թե Java պորտը։ Հոսթինգի համար ապահովեք տվյալների կայուն սկավառակ և կրկնօրինակում։

## Մեծահասակների գրանցում

Գրանցումը ստուգում է, որ ծննդյան ամսաթվով օգտատերը 18 կամ ավելի տարեկան է, և պահանջում է 18+ checkbox-ի հաստատում։ Սա ինքնահայտարարություն է, ոչ թե անձը հաստատող փաստաթղթի ստուգում։
