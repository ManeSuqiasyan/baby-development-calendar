# Baby Development Calendar

Փոքր Java ծրագիր, որը ցուցադրում է երեխայի անունը, ծննդյան ամսաթիվը և տարիքը՝ տարիներով, ամիսներով ու օրերով։

## Գործարկում

Պետք է տեղադրված լինի Java։ Ծրագրի աղբյուրի ֆայլերը գտնվում են `src` պանակում։

IntelliJ IDEA-ում բացիր նախագիծը և գործարկիր `Main` class-ի `main` մեթոդը։

Ծննդյան ամսաթիվն ու անունը փոխելու համար խմբագրիր `src/Main.java`-ի այս տողերը.

```java
baby.name = "Արամ";
baby.birthDate = "2026-09-07";
```

Ամսաթիվը գրիր `YYYY-MM-DD` ձևաչափով, օրինակ՝ `2026-09-07`։
